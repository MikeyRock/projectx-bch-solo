Node & Pool Connection Guide

Step 1 — Set Payout Address
Open Settings and enter your BCH mainnet address in Payout Address. Use the bitcoincash:q… CashAddr format. Never reuse a hot wallet address.
Step 2 — Set RPC Credentials
In Settings set RPC Username and a strong RPC Password. These must match the values passed to bitcoind -rpcuser / -rpcpassword. Default user is bchrpc.
Step 3 — Set LAN IP
Click Set LAN IP in the header and enter your Umbrel device's local IP (e.g. 192.168.1.100). This builds the stratum URL your miners connect to.
Step 4 — Point Your Miner
Use the Copy URL or Copy Config buttons. Set your miner's Pool URL to the stratum address, worker to any name, password to x.
